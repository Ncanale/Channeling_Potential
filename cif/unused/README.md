CIF files kept for reference but not used by the code.

- `AMS_DATA (1).cif`: silicon at T = 1573 K (Wyckoff 1963, AMCSD 0011244). Use only for high-T lattice-expansion tests.
- `AMS_DATA (2).cif`: zircon ZrSiO4 (Robinson et al. 1971, AMCSD 0000237). Not a channeling material of interest here.
- `PbWO4_mp-504591_primitive.cif`: Materials Project mp-504591, monoclinic **raspite** polymorph. The scintillator PWO is tetragonal scheelite (stolzite, I4_1/a): use `PbWO4.cif` in the repository root.
